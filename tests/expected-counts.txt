# tests/expected-counts.txt — floor on the number of tests each binary must run.
#
# Why this file exists
# -------------------
# run-qt-tests.sh already refuses a binary that produces no successful test body
# at all. That catches a suite reduced to nothing; it does not catch a suite
# reduced from 62 tests to 1, which stays green.
#
# That is not hypothetical. A stale in-tree `.moc` — left by an earlier in-tree
# build, and picked up in preference to the freshly generated one because the
# compiler resolves `#include "tst_X.moc"` from the source directory first — was
# found to hide a newly added test: the binary embedded an out-of-date
# metaobject, reported one test fewer, and the suite passed. Two tests were
# masked that way, in tst_CliParser and tst_UpdateChecker.
#
# Format
# ------
#   <binary-name> <minimum-passed> [platform]
#
# `platform` is the value of `uname -s`, normalised: Linux, Darwin, Windows.
# A line without a platform applies everywhere. The most specific match wins.
# `minimum-passed` counts the `N passed` of the QtTest summary, data-driven rows
# included — a test that turns into a skip lowers it too, which is the point.
#
# It is a FLOOR, not an exact count: adding tests never requires touching this
# file. Only removing them does, which is precisely the decision worth making
# explicit.
#
# A binary with no applicable line is reported as unpinned and does NOT fail the
# run. Each floor is measured on its named platform; unmeasured combinations
# remain unpinned. Extending coverage means running the suite there once and
# adding the observed count. Windows ACL floors require an elevated process.
#
# Measured 2026-09-14, Linux / Qt 6.11.1, with NGPOST_BIN set.

# Other Windows suites and macOS
# ------------------------------
# Not yet measured. These suites run MORE tests on Windows than on Linux, so
# the Linux figures above cannot be reused as a floor for them — and asserting a
# number measured nowhere is how a check like this breaks a green build:
#
#   tst_WindowsBindHelper    7 slots, all QSKIP'd off Windows
#   tst_WindowsCommandLine   5 slots, 2 of them behind #ifdef Q_OS_WIN
#   tst_VpnE2E_WireGuard     needs root, iproute2 and the privileged helper
#
# To pin them: run the suite on that platform, read the `N passed` of each
# summary, and add `<binary> <N> Windows` (or `Darwin`) lines here. Until then
# those binaries are reported as unpinned on every platform, which is honest
# about what is actually guarded.
